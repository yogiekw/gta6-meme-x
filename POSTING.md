# Cara posting meme ini di X (untuk Bos, dari HP)

Muse tidak bisa posting ke X sendiri (login X di Simular Box sedang stuck),
jadi Bos yang posting dari HP. Langkahnya:

## 1. Ambil gambarnya
Download `meme.png` dari repo ini (atau dari file yang Muse kirim di chat).
Itu gambar meme-nya, 1080×1080, siap posting.

## 2. Buat post baru di X
- Buka aplikasi X, ketuk tombol posting.
- Lampirkan `meme.png` sebagai gambar PERTAMA (dan satu-satunya).
- Pastikan akun X-nya publik (bukan protected) dan postingannya publik.

## 3. Tempel teks ini persis (jangan diubah)

Yang wajib ada di teks: link bounty make.fun, play code
`makefun-porridge-desert-inkwell`, dan tag `@makefunai`.

## 4. Posting
- Posting sebelum deadline: **Minggu 23 Nov 2026 jam 21.00 WIB**.
- Biarkan postingan dan akun tetap publik sampai hasil keluar (8 Des 2026).

## 5. Kirim link postingannya ke Muse
Salin alamat postingan (misal `https://x.com/<handle>/status/<id>`) dan
kirim ke Muse. Muse akan memasukkannya ke `POST.json`, lalu submit entry.
